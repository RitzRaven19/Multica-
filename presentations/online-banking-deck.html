03

Project Overview

01 · Project overview

One simulation, four accountable groups

Real banking teams run business analysis, architecture, QA and defect triage as one continuous chain. Student projects usually don't — so this charter forces the chain to hold, group to group.

The problem

Ambiguous requirements, untestable designs, weak handoffs — and no way to say whether a broken feature is a defect or an undocumented new ask.

The structure

Ritu & Team — business analysis · Mohit & Team — architecture & build · Mandeep & Team — QA · Adiba & Team — defect RCA. Each hands the next approved, source-linked artifacts.

The bar

Every agent output must be reviewable, reproducible, schema-valid and source-linked — subject to human approval before it counts.

Onboarding + KYC Login / Logout Money transfer Money receive Statement view Statement download out: beneficiaries out: real verification out: real money movement

Proposed Solution

03 · Agents & workflow

Three agents, one gate between each

Each agent reads only the previous stage's approved/ folder — never raw/ — so nothing unreviewed travels downstream. uat-generator is the join point: the only stage that sees every approved file at once.

brd-agentwrites brd.json, business_rules.json, open_questions.json
frd-agentwrites frd.json, data_spec.json, error_catalogue.json
uat-generatorwrites acceptance_criteria.json, uat_cases.json, traceability_matrix.csv
doc-evaluator-agentnew — scores peer BRD/FRD/UAT submissions against business_rules.json

Qualitative

Schema-valid, not eyeballed. verify_pipeline.py checks every JSON deliverable on every push and opens an issue on failure.

No docx drift. Each agent renders its own Word doc from the JSON/Markdown it just wrote, so the human-readable copy always matches.

Human-gated, not autonomous. raw/ output is invisible one stage downstream — only approved/ ever gets read.

Auditable for Group 5. traceability_matrix.csv turns "defect or new request?" into a lookup, not a debate.

Exclusions are explicit. 5 of the 20 rules are marked out-of-scope by design, so they never masquerade as coverage gaps.
